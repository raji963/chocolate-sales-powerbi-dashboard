# 🍫 Chocolate Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing chocolate sales data using Microsoft Power BI. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations and reports.

The objective is to understand sales performance, identify top-performing products, analyze regional performance, and evaluate shipment status.

## 🎯 Project Objectives

- Analyze overall chocolate sales performance.
- Identify best-selling products and product categories.
- Compare sales across countries and regions.
- Evaluate team and salesperson performance.
- Analyze order and shipment status.
- Generate meaningful business insights and recommendations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Microsoft Excel** – Data handling and preparation.
- **DAX** – Calculations and measures.
- **Data Analysis** – Identifying trends and business insights.

### 🧹 Data Cleaning & Preparation

Data preparation was performed to make the dataset suitable for analysis.

- Reviewed the dataset and checked data quality.

- Checked data formats and consistency.

- Prepared date and category fields for analysis.

- Organized data for reporting and visualization.

- Used relevant fields to support accurate calculations.

## 🗂️ Data Model

Created relationships between four tables in Power BI to support sales analysis.

- **Shipments:** Sales and shipment details.
- **Products:** Product information.
- **Locations:** Country and region details.
- **People:** Salesperson and team details.

Connected the tables using common fields to analyze sales across different business categories.

## 📐 Key DAX Measures

DAX (Data Analysis Expressions) was used to create calculated measures and evaluate key business performance indicators.

**Measures developed in this project:**

| DAX Measure | Purpose |
|---|---|
| Total Sales | Calculates overall sales revenue |
| Total Boxes | Calculates the total number of boxes sold |
| Profit Margin | Measures profitability as a percentage of sales |
| Total Shipments | Counts unique shipment records |
| Average Sales per Salesperson | Calculates average sales for each salesperson |

These measures were used to build KPI cards, analyze sales performance, compare business results, and support interactive dashboard reporting.
